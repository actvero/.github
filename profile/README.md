# Actvero

面向团队的开源 AI 能力管理平台，统一管理模型、MCP 工具、Skills 与专家。

我们希望让 AI 能力更容易被配置、共享和使用。通过统一的身份与权限，让团队成员使用已授权的 AI 资源，并支持自行部署。
